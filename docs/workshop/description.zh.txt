[h1]Brotato Combat Tracker — 伤害统计[/h1]

竖向多级浮窗，多人时按[b]玩家[/b]、再按[b]武器 / 物品[/b]拆分[b]输出、承伤、治疗[/b]，按波次自动分段；仿 ACT 的战斗记录窗口可回看每一波、逐条查看事件，导出 CSV。设置都能在游戏里改，界面文本跟随游戏语言（中文 / English）。

[b]只读统计，不修改任何游戏数值。[/b]

[h2]功能[/h2]
[list]
[*]浮窗：多人时玩家 → 武器 / 物品 / 其他 → 各个来源，单人从分类开始；每一行一条斜切色条，显示每秒、总量、占比，点一下折叠 / 展开；同名同品质的武器合成一行，如「冲锋枪 III ×2」
[*]点来源那一行看环形图明细：命中形式（直接命中 / 燃烧 / 爆炸）、打了哪些敌人、暴击占比
[*]三个视图：输出 / 承伤（被哪些敌人打、闪避多少）/ 治疗（生命再生、生命窃取、物品、消耗品）
[*]战斗记录（F8）：本局每一波的表格、每秒伤害曲线、拆分表和环形图；也能切到逐条事件，看每一次伤害、承伤和治疗
[*]设置界面（浮窗或战斗记录上的齿轮）：缩放、斜切、背景浓淡、统计口径、热键、玩家颜色都能直接改
[*]每局的战斗事件自动存成日志，可导入按新版本重新解析
[*]燃烧、爆炸、炮塔、地雷、反击、被魅惑的敌人都按游戏自己的记账规则归到对应的武器或物品
[/list]

[h2]多人[/h2]
[list]
[*]本地合作：所有玩家都统计，可按来源或按玩家查看
[*]兼容创意工坊联机 Mod [b]BrotatoOnline[/b]：每人统计自己的玩家并互传，队友也装了本 Mod 就能看到全队的数据；没装的队友不受任何影响
[/list]

[h2]按键[/h2]
[list]
[*][b]F9[/b] 显示 / 隐藏浮窗
[*][b]F8[/b] 战斗记录
[*][b]F10[/b] 重置当前统计
[*][b]F11[/b] 导出当前这一段 CSV
[/list]

浮窗平时只有文字和色条，鼠标移上去才显示背景和按钮；只在波次进行中显示，暂停菜单、升级选择、商店里自动让开。设置存在 %APPDATA%\Brotato\CombatTracker\config.cfg。
